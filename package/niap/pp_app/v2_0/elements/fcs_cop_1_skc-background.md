**Requirement:** FCS_COP.1/SKC · **Status:** Selection-Based

**FCS_COP.1.1/SKC** The **application** shall [**selection**: perform, invoke the platform to perform] [*encryption and decryption*] in accordance with a specified cryptographic algorithm

[**selection**:
- AES-CBC (as defined in NIST SP 800-38A) mode
- AES-GCM (as defined in NIST SP 800-38D) mode
- AES-XTS (as defined in NIST SP 800-38E) mode
- AES-CCM (as defined in NIST SP 800-38C) mode
- AES-CTR (as defined in NIST SP 800-38A) mode
]

and cryptographic key size of [*256-bits*].
