**Requirement:** FCS_HTTPS_EXT.1 · **Status:** Selection-Based

**FCS_HTTPS_EXT.1.1** The application shall implement the HTTPS protocol as a [**selection**: client, server, server with mutual authentication] that complies with RFC 2818.

**FCS_HTTPS_EXT.1.2** The application shall implement HTTPS using TLS as defined in the Functional Package for TLS.

**Dependencies:** FCS_TLS_EXT.1 TLS Protocol
