**FPT_API_EXT.2.1**

*Application note:* The IANA MIME types are listed at [http://www.iana.org/assignments/media-types](http://www.iana.org/assignments/media-types) and include many image, audio, video, and content file formats.

This requirement does not apply if providing parsing services is the purpose of the application.

**Evaluation activities**

*TSS:*

The evaluator shall verify that the TSS lists any IANA MIME media types (as described by [http://www.iana.org/assignments/media-types](http://www.iana.org/assignments/media-types)) for all formats the application processes and that it maps those formats to parsing services provided by the platform.

The API shall be verified in FPT_API_EXT.1.
