**Requirement:** V3.1.6 · **Level:** 1 (applies at Level 1 and above) · **Phase:** V3 Integrate (CI*) · **Sub-category:** V3.1 Security of Pipeline Environment

Verify that text coming from outside the organization, such as a contributor's branch name, commit message, or pull request title, is never inserted directly into a command that the pipeline runs.
