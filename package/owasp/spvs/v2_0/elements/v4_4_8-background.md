**Requirement:** V4.4.8 · **Level:** 2 (applies at Level 2 and above) · **Phase:** V4 Release (CD*) · **Sub-category:** V4.4 Secure Deployment Practices

Verify that a publishing identity authorized to release more than one package cannot release new versions of multiple packages within a defined time window without additional approval, or that an equivalent detective control automatically blocks further releases from that identity when such activity occurs.

**Tags:** deployment; identity; change-control; monitoring
