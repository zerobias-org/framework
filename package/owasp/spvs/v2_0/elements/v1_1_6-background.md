**Requirement:** V1.1.6 · **Level:** 3 (applies at Level 3 and above) · **Phase:** V1 Plan · **Sub-category:** V1.1 Security Requirements and Risk Assessment

Verify that build, signing, and publish each run as separate stages on independently managed systems, so that breaking into one stage doesn't automatically give access to the next.
