**Requirement:** V4.4.3 · **Level:** 2 (applies at Level 2 and above) · **Phase:** V4 Release (CD*) · **Sub-category:** V4.4 Secure Deployment Practices

Verify that production configuration secrets are stored in a secrets manager, or in encrypted configuration files whose encryption keys are held in a separate key management service or hardware security module.
