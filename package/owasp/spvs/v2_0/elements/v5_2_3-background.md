**Requirement:** V5.2.3 · **Level:** 2 (applies at Level 2 and above) · **Phase:** V5 Operate · **Sub-category:** V5.2 Security Standard Enforcement

Verify that every software component running in production can be traced to a current, pinned SBOM generated by the build pipeline and validated before deployment, confirming nothing was installed outside the approved build process.
