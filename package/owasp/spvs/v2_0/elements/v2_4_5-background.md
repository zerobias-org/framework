**Requirement:** V2.4.5 · **Level:** 1 (applies at Level 1 and above) · **Phase:** V2 Develop · **Sub-category:** V2.4 AI-Assisted Secure Development Controls

Verify that Artificial Intelligence (AI)-generated infrastructure as code (IaC) passes through the same automated misconfiguration analysis as all other IaC before merge or deployment, with no bypass for AI tool or agent identities.
