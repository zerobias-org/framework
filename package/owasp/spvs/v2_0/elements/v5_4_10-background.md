**Requirement:** V5.4.10 · **Level:** 3 (applies at Level 3 and above) · **Phase:** V5 Operate · **Sub-category:** V5.4 Detection & Monitoring

Verify that developer endpoints generate alerts when an installed extension, add-on, or tool bundle produces anomalous behavior, including network egress from test runners or build tools, reads of credential files outside the user session context, or process activity inconsistent with the approved purpose of the tool.

**Tags:** endpoint; monitoring; developer-tools
