**Requirement:** V1.6.9 · **Level:** 1 (applies at Level 1 and above) · **Phase:** V1 Plan · **Sub-category:** V1.6 Developer Tool Operation

Verify that opening a cloned or downloaded repository in a developer tool cannot trigger automatic code execution, including workspace task auto-run, tool activation hooks, and container initialization, until the user has explicitly assigned trust to that workspace.
