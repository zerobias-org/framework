**Requirement:** V3.1.12 · **Level:** 2 (applies at Level 2 and above) · **Phase:** V3 Integrate (CI*) · **Sub-category:** V3.1 Security of Pipeline Environment

Verify that dependency installation and build execution occur in an isolated environment whose outbound network access is denied by default and permitted only to approved package sources and explicitly approved endpoints, so that code executing during install or build cannot download additional stages or send data to arbitrary destinations.

**Tags:** network; build; dependencies
