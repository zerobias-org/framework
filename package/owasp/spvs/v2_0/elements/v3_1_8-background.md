**Requirement:** V3.1.8 · **Level:** 2 (applies at Level 2 and above) · **Phase:** V3 Integrate (CI*) · **Sub-category:** V3.1 Security of Pipeline Environment

Verify that build and publish run as separate pipeline stages with the built artifact held between them for review, and that no single pipeline run can both build and publish without that check.
