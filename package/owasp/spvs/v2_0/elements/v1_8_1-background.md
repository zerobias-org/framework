**Requirement:** V1.8.1 · **Level:** 1 (applies at Level 1 and above) · **Phase:** V1 Plan · **Sub-category:** V1.8 Source Code Management Hardening

Verify that the Version Control System (VCS) enforces role-based access control (RBAC) using documented role definitions that grant each role only the permissions it requires.
