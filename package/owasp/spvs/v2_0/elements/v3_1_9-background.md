**Requirement:** V3.1.9 · **Level:** 2 (applies at Level 2 and above) · **Phase:** V3 Integrate (CI*) · **Sub-category:** V3.1 Security of Pipeline Environment

Verify that every change to a pipeline or workflow file is scanned by an automated tool before it's merged, checking for unsafe triggers, unescaped external input in commands, and permissions broader than needed.
