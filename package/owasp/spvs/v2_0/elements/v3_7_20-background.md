**Requirement:** V3.7.20 · **Level:** 3 (applies at Level 3 and above) · **Phase:** V3 Integrate (CI*) · **Sub-category:** V3.7 Continuous Security Checks

Verify that security scanning tools are themselves checked for integrity before they run, so a compromised scanning tool can't falsely mark its own output as clean.
