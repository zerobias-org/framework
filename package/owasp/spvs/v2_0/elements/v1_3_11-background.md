**Requirement:** V1.3.11 · **Level:** 2 (applies at Level 2 and above) · **Phase:** V1 Plan · **Sub-category:** V1.3 Identity and Access Management

Verify that source code repository read access for all identities, including human users and programmatic identities such as service accounts, CI/CD tokens, and bot accounts, is scoped by team or project and is not granted organization-wide by default.
