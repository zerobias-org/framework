**Requirement:** V3.4.9 · **Level:** 2 (applies at Level 2 and above) · **Phase:** V3 Integrate (CI*) · **Sub-category:** V3.4 Credential Hygiene

Verify that when a publish workflow has both a short-lived OIDC credential and a static token configured, the static token is removed rather than left as a silent fallback.
