**Requirement:** V3.1.7 · **Level:** 1 (applies at Level 1 and above) · **Phase:** V3 Integrate (CI*) · **Sub-category:** V3.1 Security of Pipeline Environment

Verify that build and CI/CD pipelines install dependencies using a command that installs exactly what's listed in the lockfile, instead of a command that can pull in newer versions on its own.
