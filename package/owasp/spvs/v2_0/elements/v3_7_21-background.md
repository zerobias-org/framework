**Requirement:** V3.7.21 · **Level:** 3 (applies at Level 3 and above) · **Phase:** V3 Integrate (CI*) · **Sub-category:** V3.7 Continuous Security Checks

Verify that dependency installation and build steps in pipeline build environments run in an instrumented environment, and that a child process, script interpreter launch, or network connection that is not expected for the declared build triggers an alert.

**Tags:** monitoring; build; dependencies
