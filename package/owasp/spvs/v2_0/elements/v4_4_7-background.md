**Requirement:** V4.4.7 · **Level:** 3 (applies at Level 3 and above) · **Phase:** V4 Release (CD*) · **Sub-category:** V4.4 Secure Deployment Practices

Verify that the release stage accepts only credentials issued specifically for release and refuses any credential carried over from the integrate stage or any earlier stage.
