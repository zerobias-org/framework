Assessment is required when: the online service requires federation. See AL-1.

If federation will be used, see CIL controls for impact levels.

**Assessment objective**

Determine if an initial FAL for each user group was determined and is based on the impact level determination (see  CIL requirements)

**Assessment methods**

- EXAMINE: Examine the documentation to verify that the initial FAL has been determined for each user group and is based on the effective impact level determination (See CIL controls).
