Storage of personal information is a form of processing.

SECC-1 requires IdPs and CSPs to implement at least moderate baseline security controls.

SECC-3 requires RPs that request or process personal information to implement at least moderate baseline security controls.

**Assessment objective**

Determine whether the IdP and RP store personal information in subscriber accounts using tailored security controls from [SP800-53] or an equivalent standard.

**Assessment methods**

- EXAMINE: For IdPs, satisfied by SECC-1. For satisfied by SECC-3.
