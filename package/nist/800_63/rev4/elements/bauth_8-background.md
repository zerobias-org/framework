**Applies to:** RP · **Assurance level:** FAL3 · **Section:** SP 800-63C-4 3.16 H

The RP SHALL send a notification to the subscriber via an out-of-band mechanism (e.g., an email to an address previously associated with the subscriber)...if any of the following events occur:

- (a) A new bound authenticator is added to the RP subscriber account.
- (b) An existing bound authenticator is removed from the RP subscriber account.
