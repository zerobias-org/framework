Assessment is required when: An Identity API is offered by the IdP.

Access to the identity API should be limited to the duration of the federation transaction plus the time necessary to synchronize attributes (see Sec. 4.6.4). Time limits prevent indefinite access to subscriber attributes after a federation transaction.

**Assessment objective**

Determine whether access to the identity API is time-limited as specified in the trust agreement artifact(s).

**Assessment methods**

- EXAMINE: Examine the relevant trust agreement artifact(s) to verify that they specify time limits for identity API access. Review the IdP's identity API configuration to verify that access is time-limited in accordance with the trust agreement artifact(s).
