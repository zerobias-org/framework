**Applies to:** Verifier/CSP · **Assurance level:** ALL · **Section:** SP 800-63B-4 3.1.2.2 F

Look-up secrets that are shorter than the minimum security strength specified in the latest revision of [SP800-131A] (i.e., 112 bits as of the date of this publication) SHALL be stored in a salted and hashed form using a suitable password hashing scheme, as described in Sec. 3.1.1.2.
