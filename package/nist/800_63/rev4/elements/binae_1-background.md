**Applies to:** CSP · **Assurance level:** ALL · **Section:** SP 800-63B-4 4.1.2.2 A

The binding process SHALL proceed in one of the following ways:

- (1) An endpoint that has authenticated to the CSP requests a binding code from the CSP. The binding code is input into the endpoint associated with the new authenticator and sent to the CSP.
- (2) The endpoint associated with the new authenticator obtains a binding code from the CSP. The binding code is input to an authenticated endpoint and sent to the CSP.
