**Applies to:** CSP · **Assurance level:** IAL3 · **Section:** SP 800-63A-4 4.3.4 #1

Each piece of FAIR or STRONG evidence that is presented SHALL be validated using one of the following techniques:

- (a) Confirming the authenticity of the digital evidence by interrogating the digital security features (e.g., signatures on assertions or data).
- (b) Confirming the authenticity of the physical evidence using automated scanning technology that can detect physical security features.
- (c) Confirming the integrity of any physical security features through a visual inspection by a proofing agent using a real-time or asynchronous process (e.g., offline manual review).
