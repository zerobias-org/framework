**Assessment objective**

Determine whether the CSP creates a unique attribute bundle for each requesting wallet.

**Assessment methods**

- EXAMINE: Examine the CSP's attribute bundle issuance process to verify that each bundle is uniquely bound to the requesting wallet (e.g., by including the wallet's verification key per IABSCW-1 #4).
- TEST: Test by requesting attribute bundles from the CSP using two different wallets for the same subscriber. Compare the bundles and verify they are distinct.
