**Assessment objective**

If a CSP employs automated image analysis algorithms, confirm that is has documented the types of attack artifacts that were tested and the corresponding false negatives and that this information has been made available to any of its RPs that request it.

**Assessment methods**

- EXAMINE: Examine the CSP's testing procedures and results to determine which attack artifacts were tested and the corresponding false negative rates.
- EXAMINE: Examine an example contract for an RP to determine it includes the option for RPs to request this information.
