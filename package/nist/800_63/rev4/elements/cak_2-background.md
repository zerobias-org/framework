**Applies to:** CSP · **Assurance level:** Syncable · **Section:** SP 800-63B-4 B.2 #2

Authentication keys that are cloned or exported from a device to a sync fabric SHALL only be stored in an encrypted form using a key with the minimum security strength specified in the latest revision of [SP800-131A] (i.e., 112 bits as of the date of this publication).
