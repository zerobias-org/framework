**Applies to:** CSP · **Assurance level:** IAL3 · **Section:** SP 800-63A-4 4.3.8 #6

For kiosk-based on-site attended identity proofing, all devices used to support interaction between the proofing agent and the applicant SHALL be protected by appropriate baseline security features that are comparable to at least FISMA moderate controls, including malware protection, administrator-specific access controls, and software update processes.
