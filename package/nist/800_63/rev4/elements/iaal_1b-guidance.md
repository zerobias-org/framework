Assessment is required when: the online service requires authentication. See AL-1.

If authentication is required, see CIL controls for impact levels.

**Assessment objective**

Determine if an initial AAL for each user group was determined and is based on the impact level determination (see  CIL requirements)

**Assessment methods**

- EXAMINE: Examine the documentation to verify that the initial AAL has been determined for each user group and is based on the effective impact level determination (See CIL controls).
