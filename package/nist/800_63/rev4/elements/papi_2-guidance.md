Assessment is required when: The IdP provides a provisioning API.

**Assessment objective**

Determine whether the trust agreement artifact(s) document the requirements for provisioning API access.

**Assessment methods**

- EXAMINE: Examine the trust agreement artifact(s) to verify adequate documentation of the following: (1) the purpose for provisioning API access; (2) the set of attributes made available to the RP; (3) whether the API functions as push, pull, or both; and (4) the population of subscribers whose attributes are made available.
