**Applies to:** CSP/Verifier · **Assurance level:** ALL · **Section:** SP 800-63B-4 3.1.3.1 C

Email SHALL NOT be used for out-of-band authentication because it may be vulnerable to:

- (a) Access using only a password.
- (b) Interception in transit or at intermediate mail servers.
- (c) Rerouting attacks, such as those caused by Domain Name System (DNS) spoofing.
