**MUST:** Providers MUST notify FedRAMP within 5 business days of denying an agency access request for FedRAMP Certification Data.

**Applies to:** Class B, Class C (Providers)

**Audience:** Using a Trust Center. These rules apply to providers that are using a FedRAMP-compatible trust center instead of USDA Connect; they DO NOT apply to providers using USDA Connect.

**Timeframe:** 5 bizdays

### Notification

- party: FedRAMP
- method: form
- target: https://help.fedramp.gov/hc/en-us/requests/new?ticket_form_id=51829826617243
- name: [CSP] Agency Access Denial

## Defined terms

- **Certification Data:** The collective information required by FedRAMP for initial and ongoing FedRAMP Certification of a cloud service offering, including the FedRAMP Certification Package.
