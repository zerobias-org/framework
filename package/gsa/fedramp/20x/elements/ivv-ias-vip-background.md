**MUST:** Assessors MUST verify that information supplied during a FedRAMP independent assessment is included in the FedRAMP Certification Package by the provider without inappropriate modification.

**Applies to:** Class B, Class C (Assessors)

**Audience:** General Independent Assessor Responsibilities. These rules apply to independent assessment services supporting all FedRAMP Certification types.

### Notes

- This rule is related to IVV-CSO-ICP (Inclusion in Certification Package).

### Related

- IVV-CSO-ICP

## Defined terms

- **Certification Package:** Has meaning from 44 USC § 3607 (b)(8) given to "authorization package", which is "the essential information that can be used by an agency to determine whether to authorize the operation of an information system or the use of a designated set of common controls for all cloud computing products and services [certified] by FedRAMP."
- **FedRAMP Independent Assessment:** An independent verification and validation assessment, performed by a FedRAMP Recognized independent assessment service or FedRAMP following FedRAMP rules. These assessments are typically first performed to obtain an initial FedRAMP Certification then repeated on an annual basis to maintain FedRAMP Certification.
- **Verification:** Confirmation through objective evidence that specified FedRAMP Practices have been fulfilled for a cloud service offering.
