**SHOULD:** Providers SHOULD configure agency tenants by default to use cryptographic services that use cryptographic modules or update streams of cryptographic modules with active validations under the NIST Cryptographic Module Validation Program when such modules are available.

**Applies to:** Class B, Class C (Providers)

**Audience:** Cloud Service Provider Responsibilities. These rules apply to providers for FedRAMP Certifications.

### Artifacts

- List of cryptographic modules used by default including whether these modules are validated under the NIST Cryptographic Module Validation Program or are update streams of such modules.

## Defined terms

- **Validation:** Confirmation through objective evidence that implemented security capabilities and related certification data are suitable for their intended FedRAMP Certification use and support the expected security outcomes for a cloud service offering.
