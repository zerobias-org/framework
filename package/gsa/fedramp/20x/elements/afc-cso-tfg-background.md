**MUST:** Providers MUST treat any email originating from an @fedramp.gov or @gsa.gov email address as if it was sent from FedRAMP by default; if such a message is confirmed to originate from someone other than FedRAMP then the FedRAMP Security Inbox rules no longer apply.

**Applies to:** Class B, Class C (Providers)

**Audience:** General Provider Responsibilities. These rules apply to providers with any type of FedRAMP Certification.

### Artifacts

- Configuration settings for FSI mailbox
- Automated validation to check FSI mailbox configuration

## Defined terms

- **FedRAMP Security Inbox:** An email address that follows the FedRAMP Security Inbox rules.
