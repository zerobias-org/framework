**SHOULD:** Providers SHOULD promptly and automatically acknowledge the receipt of messages received from FedRAMP in their FedRAMP Security Inbox.

**Applies to:** Class B, Class C (Providers)

**Audience:** General Provider Responsibilities. These rules apply to providers with any type of FedRAMP Certification.

## Defined terms

- **FedRAMP Security Inbox:** An email address that follows the FedRAMP Security Inbox rules.
- **Promptly:** Without unnecessary delay.
