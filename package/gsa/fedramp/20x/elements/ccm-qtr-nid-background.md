**MUST NOT:** Providers MUST NOT irresponsibly disclose sensitive information in a Quarterly Review that would likely have an adverse effect on the cloud service offering.

**Applies to:** Class B, Class C (Providers)

**Audience:** Quarterly Reviews. These rules for Quarterly Reviews apply to providers with any type of FedRAMP Certification.

## Defined terms

- **Cloud Service Offering:** A specific, packaged cloud computing product or service supplied by a cloud service provider for use by customers, that is the subject of a FedRAMP Certification.
- **Likely:** A reasonable degree of probability based on context.
- **Quarterly Review:** A regular synchronous meeting hosted by a FedRAMP Certified cloud service provider for agency customers, following FedRAMP Collaborative Continuous Monitoring rules.
