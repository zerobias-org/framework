**MUST:** Providers MUST notify FedRAMP using the FedRAMP Marketplace Provider Listing Request Form to request a listing in the FedRAMP Marketplace.

**Applies to:** Class A, Class B, Class C (Providers)

**Audience:** General Provider Responsibilities. These rules apply to providers seeking a listing in the FedRAMP Marketplace.

### Notes

- FedRAMP does not accept applications for a FedRAMP Marketplace Listing via email!

- party: FedRAMP
- method: form
- target: https://help.fedramp.gov/hc/en-us/requests/new?ticket_form_id=50939227168027
