**MUST:** Providers MUST publicly supply the target date for their next Quarterly Review with other public FedRAMP Certification Data.

**Applies to:** Class B, Class C (Providers)

**Audience:** Quarterly Reviews. These rules for Quarterly Reviews apply to providers with any type of FedRAMP Certification.

## Defined terms

- **Certification Data:** The collective information required by FedRAMP for initial and ongoing FedRAMP Certification of a cloud service offering, including the FedRAMP Certification Package.
- **Quarterly Review:** A regular synchronous meeting hosted by a FedRAMP Certified cloud service provider for agency customers, following FedRAMP Collaborative Continuous Monitoring rules.
