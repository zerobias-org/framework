**MAY:** Providers MAY freshen a stale initial independent verification and validation assessment by having a FedRAMP Recognized independent assessment service review any changes between the original assessment and the current status of the cloud service offering in place of a full re-assessment, UNLESS the stale assessment is more than 9 months old.

**Applies to:** Class A, Class B, Class C (Providers)

**Audience:** Applying for FedRAMP Certification. These rules apply to cloud service providers who have met all other relevant rules and are ready to apply for any FedRAMP Certification.

## Defined terms

- **Cloud Service Offering:** A specific, packaged cloud computing product or service supplied by a cloud service provider for use by customers, that is the subject of a FedRAMP Certification.
- **FedRAMP Recognized:** The status of independent assessment services that are recognized by FedRAMP to perform assessment activities on behalf of FedRAMP for cloud service offerings seeking to obtain or maintain FedRAMP Certification.
- **Validation:** Confirmation through objective evidence that implemented security capabilities and related certification data are suitable for their intended FedRAMP Certification use and support the expected security outcomes for a cloud service offering.
- **Verification:** Confirmation through objective evidence that specified FedRAMP Practices have been fulfilled for a cloud service offering.
