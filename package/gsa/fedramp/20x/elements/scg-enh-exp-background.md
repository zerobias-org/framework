**SHOULD:** Providers SHOULD offer the capability to export all security settings in a machine-readable format.

**Applies to:** Class B, Class C (Providers)

**Audience:** Enhanced Capabilities. These recommendations apply to providers with FedRAMP Certifications of any type.

### Artifacts

- Explanation of how to access this information
- or explanation why this functionality is not available

## Defined terms

- **Machine-Readable:** Has the meaning from 44 U.S. Code § 3502 (18) which is "the term "machine-readable", when used with respect to data, means data in a format that can be easily processed by a computer without human intervention while ensuring no semantic meaning is lost"
