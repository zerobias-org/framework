Mechanisms exist to ensure Artificial Intelligence (AI) and Autonomous Technologies (AAT) system event logging capabilities at a minimum provide:

- (1) Start date, start time, end date and end time for each use;
- (2) Database(s) against which input data has been checked by the system;
- (3) Input data for which the search has led to a match; and
- (4) Identification of individual(s) involved in the verification of the results.
